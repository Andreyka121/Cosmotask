# Pipe Maze

Рішення задачі про замкнений контур із труб на Python. Беремо інпут з текстового файлу та обчислюємо дві метрикі:

- найкоротшу відстань від старту `S` уздовж контуру до його найдальшой точки.
- кількість клітинок усередині цього контуру.

## Запуск

Python 3.9 або новіший, сторонніх залежностей немає.

```bash
python maze.py
```

За замовчуванням читається `puzzle_input.txt` в тій же директорії де й `maze.py`  ,інший файл можна передати аргументом:

```bash
python maze.py path/to/input.txt
```

Результати по нашому `puzzle_input.txt` результат:

```text
Part 1: 7063
Part 2: 589
```

## Хід рішення

### Пошук контуру

Для кожного символу труби в `CONNECTIONS` задано два напрямки з'єднання. Спочатку знаходимо `S` і визначаємо його виходи за сусідніми трубами.

Після цього перевіряємо достовірність сусідів: якщо поточна труба веде праворуч, сусідня повинна мати вихід ліворуч, Також перевіряємо межі поля. Самого розташування труб поруч недостатньо.

Далі йдемо від `S` одним із двох напрямків. На кожному кроці обираємо з'єднаного сусіда, відмінного від попередньої клітинки. Обхід завершується після повернення до `S`. Координати зберігаємо в порядку обходу, старт додаємо лише один раз. Зайві труби поза головним контуром у цей список не потрапляють.

### Частина 1: відстань

Нехай `L` - довжина контуру. Якщо до клітинки в одному напрямку `k` кроків, то в іншому - `L - k`. Її відстань від старту - менше з цих двох чисел.

Найбільша така відстань досягається на половині контуру:

```python
part1 = L // 2
```

На сітці з рухом лише вгору, вниз, ліворуч і праворуч довжина замкненого контуру парна, тому ділення точне.

### Частина 2: клітинки всередині

Центри клітинок контуру утворюють багатокутник. За їхніми координатами рахуємо подвоєну площу формулою Гауса або шнурівки: для кожної пари послідовних точок додаємо `x1 * y2 - x2 * y1`, включаючи останню точку та першу. Модуль суми дає `area2` - площу, помножену на два.

Сама площа ще не є кількістю внутрішніх клітинок. Для цього використовуємо теорему Піка:

```text
A = I + B / 2 - 1
```

Тут `A` - площа, `I` - кількість внутрішніх точок із цілими координатами, `B` - кількість таких точок на межі. У нашому випадку ці точки відповідають центрам клітинок. Кожне ребро контуру має довжину один, тому `B = L`.

Звідси отримуємо:

```python
part2 = (area2 - L + 2) // 2
```

Усі обчислення цілочисельні. Модуль площі дозволяє обходити контур у будь-якому напрямку. Зайві труби всередині враховуються як звичайні внутрішні клітинки, а клітинки головного контуру не рахуються.

Такий підхід не потребує заливання поля чи збільшеної сітки для обробки вузьких проходів між трубами.

## Структура коду

- `trace_loop(text)` знаходить головний контур і повертає його координати по порядку.
- `solve(text)` обчислює та повертає пару відповідей `(part1, part2)`.
- `main()` читає файл і виводить результат.

Рішення покладається на гарантії умови: поле прямокутне, містить дозволені символи й один `S`, а контур через нього замкнений і не має розгалужень. Окремої валідації цих умов не робив. Помилки читання файлу обробляються в `main()`.

Для поля `H × W` і контуру довжини `L` час роботи та використання пам'яті - `O(H × W + L)`: зберігаємо поле й координати контуру та робимо лінійні проходи по них.

## Інтерактивна карта

Додав просту візуалізацію, щоб можна було подивитись сам маршрут і клітинки всередині.
Готовий `maze_visualization.html` можна відкрити в браузері.

Якщо міням інпут, генеруємо карту заново:

```bash
python visualize.py
```

За замовчуванням скрипт бере `puzzle_input.txt` і записує результат у `maze_visualization.html`.

Для іншого поля або назви результату:

```bash
python visualize.py path/to/input.txt -o map.html
```

На сторінці є дві фічі: повзунок для ручного проходу по маршруту і кнопку "Показати всередині".
Від `S` йдемо у двох напрямках, кожен виділяється своїм кольором.
На останньому кроці зустрічаємось у найдальшій клітинці. Жовтим підсвічуються внутрішні клітинки.
саме поле можна прокручувати всередині рамки.

Для маршруту беремо готовий `loop` із `trace_loop()`, бо координати там уже записані по порядку.
Теорема Піка дає тільки кількість внутрішніх клітинок, а для підсвічування потрібні ще їхні координати.
Їх знаходимо в `visualize.py`: проходимо рядки поля і беремо клітинки між перетинами з вертикальними ребрами контуру,
сам контур не враховуємо. Кількість звіряємо з результатом `solve()`.

По файлах:

- `visualize.py` - бере дані з розв'язання і генерує HTML.
- `maze_viewer.html` - шаблон сторінки зі стилями та JavaScript.
- `maze_visualization.html` - готова карта для нашого інпуту, можна відкрити окремо.
- `test_visualize.py` - перевірки даних для візуалізації.

Сторонніх залежностей немає. Python використовує стандартні модулі і наш `maze.py`,
на сторінці - звичайні HTML, CSS та JavaScript.
Для генерації потрібні Python, обидва скрипти, шаблон та інпут. Для перегляду готового HTML потрібен тільки браузер.

## Тести

```bash
python -m unittest -v
```

У `test_maze.py` перевіряються приклади з умови, усі форми стартової труби, контур на межі поля, вузькі проходи, зайві труби та мінімальний контур без внутрішніх клітинок.

У `test_visualize.py` звіряємо внутрішні клітинки з відповідями на тих самих прикладах,
перевіряємо їхні координати на маленькому квадраті та запис даних у HTML.
